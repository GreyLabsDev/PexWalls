## 1. What this is

Wallpaper client for Pexels (grids, Room favorites, download, wallpaper). Single module `:app`, View Binding + Fragments, Koin. **Not** Compose, **not** Data Binding.

## 2. Run locally

- JDK 17, AGP 9.3.1, Gradle 9.5.0, compileSdk 37, minSdk 30.
- `local.properties`: `sdk.dir=...` and `pexels.api.key=...` (see `local.properties.example`). Never commit that file.
- `./gradlew :app:ktlint :app:testDebugUnitTest :app:assembleDebug`
- Room: `AppDatabaseMigrations.ALL` is an **empty** array (compiles). Real schema change = version + `Migration`.

## 3. Map

Packages in `:app`: app, common, data, domain, presentation. DI: `PexWallsApp`. Nav XML, start `splashFragment`. Tabs: Home, Curated, Search, Favorites. Args: `"category"`, `"photo"`.

## 4. Flow

Home → categoryPhotos (`PhotoPagingUpdater`) → photoFragment. Network: Retrofit `Call.execute()` in `RemoteDataSource`. Tests: MockWebServer + `FakeRepository` + Room DAO (Robolectric / androidTest). See `.bob/rules/35-testing.md`.

## 5. README drift

Data Binding → View Binding. Multi-module / Compose → not on disk.

## 6. Hazards

Do not re-hardcode the Pexels token or trust-all TLS. BODY/Timber debug-only. Do not call `PexelsApi.getPhotoById`. Domain still leaks data/presentation types — don't grow them.
