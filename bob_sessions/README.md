# bob_sessions

Required by the IBM TechXchange 2026 hackathon guide.

Each team member uploads **Bob IDE task session consumption summary** screenshots here as PNG when preparing the submission.

Suggested name: `teamname_task01_short-description.png`.

Do not put API keys or IBM Cloud credentials in this folder. These files are evidence of Bob usage, not source code — they are listed in `.bobignore` so Bob does not ingest them.
